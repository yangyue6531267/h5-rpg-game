# 世界观与势力设定

## 1. 核心背景：蜀山群侠风格
本世界参考《蜀山》剑侠体系，讲究“御剑乘风”，法宝对轰，正邪对立鲜明。

### 远古传说
- **幽泉血魔**：千年前曾差点毁灭世界的魔头，被峨眉祖师镇压。（作为背景板BOSS，给主角刷经验用）

## 2. 主角宗门：墨山道 (Mo Shan Dao)

### **核心设定**
*   **宗旨**：**兼爱、非攻、尚贤、节用**。
*   **特色**：修仙界的“理工学院”。精通机关术、阵法、傀儡道。
*   **收徒规则**：**有教无类**。无论出身（乞丐、皇族、强盗），只要通过“问心局”皆可入门。
    *   *副作用*：门下弟子鱼龙混杂，有真君子，也有伪小人。
*   **传承制度**：**尚贤制**（Meritocracy）。
    *   拒绝血统世袭。每一代“巨子”（掌门）由上一代根据能力和品德指定，或者通过“墨家机关城”试炼者得之。

### **现任巨子**
*   **出身**：贫农 -> 流寇（因为活不下去落草为寇） -> 墨者。
*   **经历**：早年因饥荒带头抢粮，被前代巨子制服。前代巨子未杀他，反而教他机关术与道理。他大彻大悟，立誓要让天下人“吃饱饭，不受欺”。
*   **形象**：穿着草鞋、皮肤黝黑的老农形象。擅长用最土的材料造最狠的杀人机关（为了止战）。
*   **理念**：**“杀一人而救天下，我不为；杀一人而救百人，我犹豫；杀恶人而救善人，我……动手！”**（为了非攻，不得不攻）。

## 3. 正道五大派 (参考蜀山设定)

### **1. 峨眉 (当世第一势)**
- **地位**：万代仙宗，正道领袖。
- **驻地**：金顶云海，悬空仙山。
- **特色**：
    - **剑道独尊**：门下弟子皆修剑仙，剑气纵横。
    - **镇派之宝**：**天雷双剑**（天剑、雷剑）。由秦百川掌管，双剑合璧，可开天门。
    - **资源**：拥有修仙界唯一的“灵空天界”入口，灵气浓郁成液。

### **2. 昆仑 (孤傲隐世)**
- **特色**：**日月金轮**。
    - 昆仑弟子一师一徒传承，走精英路线。
    - 擅长合击之术，日金轮主守，月金轮主攻，攻防一体。
- **关系**：不论辈分，只论实力。对峨眉这群“人多势众”的暴发户颇有微词，但不得不服秦百川的剑。

### **3. 五台 (旁门转正)**
- **特色**：**万剑归宗**。
    - 五台山多奇僧怪道，法门庞杂。
    - 擅长炼制“子母剑”、“百灵斩仙剑”，打架喜欢以多欺少，漫天飞剑如雨。
- **掌教**：尊胜大师（和尚），与峨眉交好。

### **4. 青城 (丹鼎符箓)**
- **特色**：不是剑修，擅长炼丹和符阵。
    - 入门送“鹤驾”，青城弟子出门都是骑鹤，仙气飘飘。
    - 是修仙界最大的“药房”和“军火商”。秦无垢最大的消费对象之一。

### **5. 崆峒 (炼体苦修)**
- **特色**：**翻天印**。
    - 门人多为苦行僧打扮，肉身成圣。
    - 喜欢用法宝硬砸，招牌法宝“番天印”，专砸人天灵盖。

## 3. 魔道势力
### **赤尸神君 & 幽泉余孽**
- **特点**：擅长元神寄生，化血重生 (如赤尸)。
- **现状**：躲在“蚩尤血穴”等极阴之地，整天想着复活幽泉血魔，但每次刚冒头就被峨眉弟子当副本刷了。

## 4. 人间势力
### **大周皇朝**
- **定位**：凡人国度。
- **关系**：皇族见到峨眉的外门长老都要行跪拜礼。每年要向各大仙门进贡。

## 5. 修行境界 (标准体系)
- **练气 -> 筑基 -> 金丹 -> 元婴 -> 化神 ->渡劫**
- *注：在这个世界，拥有一件强力的本命法宝（如南明离火剑、日月金轮）往往能越阶挑战。*
