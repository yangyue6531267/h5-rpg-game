# 《道》功法与修行体系图谱

本文档旨在梳理《道》中独特的“修仙+克苏鲁+科幻”复合修炼体系，解析各类功法、神通及其背后的世界观逻辑。

---

## 1. 核心修炼体系 (Core Systems)

本书存在两套并行的修炼逻辑：**太极（旧法）**与**太素（新法）**，以及介于二者之间的**科学修仙**。

### 1.1 太极仙道 (Taiji Immortal Dao) —— "旧时代的余晖"
传统修仙体系，追求“顺应天道”，通过积累资源稳步晋升。
*   **核心资源**：灵炁（Spiritual Qi）。即被过滤、驯化后的能量。
*   **境界划分**：炼炁 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚。
*   **特点**：
    *   **循序渐进**：需要漫长时间打坐吐纳（如常人需一甲子筑基）。
    *   **稳定性高**：不仅修身，更重修心，不易异变。
    *   **瓶颈**：资源有限，阶级固化（门阀垄断灵脉）。
*   **代表势力**：峨眉、昆仑、衡山（旧玄门）。

### 1.2 太素天道 (Taisu Heavenly Dao) —— "来自深空的凝视"
本质是**“高维辐射变异”**。修仙者直视宇宙本源（不可名状的魔神/天体），引“煞气/道痕”入体。
*   **核心资源**：**心情值/SAN值 (Sanity)**。以人性与理智为燃料，换取力量。
*   **修炼逻辑**：**观（Visualization）** → **化（Transformation）**。
    *   “观”：直视高维存在（如拜月、观星）。
    *   “化”：身体与灵魂向高维形态发生**良性突变**。
*   **特点**：
    *   **极速**：悟道即可突破，瞬息千里。
    *   **极危**：容易导致SAN值归零，异化为“非物”（怪物/疯子）。
    *   **代价**：**“道化度”**。越接近道，越像怪物（如长出触手、复眼、变成虫子）。
*   **代表势力**：墨竹山（部分）、神教、罗教。

### 1.3 科学修仙 (Scientific Cultivation) —— "公司的技术降维"
由**公司 (The Company)** 传入的黑科技，在土著眼中被理解为“机关术”或“外道”。
*   **表现形式**：
    *   **辐射炼体**：利用核辐射（火毒/雷毒）进行淬体。
    *   **基因改造**：**“血神子”**本质是纳米机器人/液态生物组织；**“造畜”**是基因编辑。
    *   **义体飞升**：将意识上传至机械躯壳（机关人/法宝元神）。
    *   **克隆技术**：量产肉身容器（素体）。

## 2. 主要功法图谱 (Major Cultivation Methods)

### 2.1 墨竹山传承 (Ink Bamboo Mountain Arts)
墨竹山兼容并包，以前卫、实用、疯狂著称。

| 功法名称 | 类型 | 描述与效果 | 备注 |
| :--- | :--- | :--- | :--- |
| **太阴五罗剑鬼** | 神识/剑道 | **神藏金丹**法门。在神庭（大脑）内分化出五个独立意识（剑鬼），可一心六用。 | 主角以此法实现多线程操作（打架/挂机/聊天）。 |
| **北辰剑典** | 剑道 | 借引星辰之力（实为宇宙射线/引力波），剑气恢弘浩大，无坚不摧。 | 玄天剑祖招牌，需极高计算力（算力即剑心）。 |
| **太煞剑典** | 毁灭/剑道 | 引**太煞（熵增/虚空能量）**入剑，万物皆杀，触之即湮灭。 | 极度危险，主角飞升后的本命道法。 |
| **墨山机关术** | 制造/外物 | 制造动力装甲（机关傀儡）、浮空战舰、自动化生产线。 | 核心已达工业革命/早期科幻水平。 |
| **天蚕九变** | 炼体/虫道 | **菀窳仙界**（虫族位面）的根本法。模拟昆虫变态发育，每一次蜕皮实力暴涨。 | 主角用于适应异界环境，化身大扑棱蛾子。 |

### 2.2 罗教/神教传承 (Cult Arts)
追求极致的进化与生存，往往伴随严重的肉体变异。

| 功法名称 | 类型 | 描述与效果 | 备注 |
| :--- | :--- | :--- | :--- |
| **血神子** | 炼体/不死 | 将全身血液炼化为**“血影”**（液态生命）。可无限分裂、滴血重生、侵蚀夺舍。 | 罗祖/李药师绝学。克星是强光/高温（如激光/正阳火）。 |
| **太玄经** | 精神/控制 | **“他化自在”**。通过精神连接侵蚀他人心智，将其转化为傀儡或分身。 | 神主/公司控制信徒的手段（类似蜂巢意识网络）。 |
| **千面魔形** | 变化/伪装 | 可以完美模拟任何人的外貌、气息甚至因果。 | 主角（千面仙人）的核心能力，用于开马甲。 |
| **造畜之术** | 变异/刑罚 | 强行改变生物的物种形态（如把人变成羊、把狗变成麒麟）。 | 神教常用手段，也是生物兵器制造法。 |

### 2.3 旁门左道与特殊能力

*   **拜月法**：
    *   直视“太阴”（月球/公司基地），获取巨量太素道息。
    *   **效果**：快速回蓝/升级，但扣除大量心情值（SAN check）。
*   **心情系统 (The System)**：
    *   主角李凡独有的金手指。
    *   **【冷静一下】**：强制锁定SAN值，免疫精神污染，并将溢出的精神冲击转化为“心情值”（货币）。
    *   **【扫描】**：数字化解析目标属性、功法弱点。
    *   **【加点】**：消耗心情值直接提升功法熟练度或推演新法。

## 4. 武器与法宝 (Artifacts & Weapons)

*   **飞剑 (Flying Swords)**：
    *   不仅是剑，更是**“浮游炮”**。高阶飞剑搭载智能剑灵（AI）。
*   **法相 (Dharma Idol)**：
    *   本质是**“机甲/外骨骼”**。元婴/化神修士战斗时开启的巨大化能量形态。
*   **玄女天书**：
    *   看似是画卷，实则是**二维化武器/数据库**。
*   **烛龙**：
    *   **生物战舰**。长达数千里的巨型活体飞船，拥有毁灭地表的火力。
