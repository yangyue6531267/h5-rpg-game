# 人物小传 (Character Biographies)

## 主要角色 (Main Cast)

### 陈道 (Chen Dao)
*   **原名**: 李凡 (Li Fan)
*   **身份**: 墨山道入门弟子 -> 筑基修士 -> 资深玩家
*   **核心设定**: “东北血牛刺客”。
*   **金手指**: 【修仙游戏化系统（毒舌吐槽版）】。不仅显示数值，还会用东北话吐槽宿主。
*   **武器**: **【过河卒】** (Guo He Zu)。
    *   **描述**: 苏灵韵赠送的下品法器飞剑。剑身漆黑，刃口雪亮。名为“过河卒”，意为“卒子过河，有进无退”。
*   **性格**: 东北吐槽怪，搞笑男，虽然看着像个混不吝的该溜子，实则是为了生存不择手段的高玩。满嘴大碴子味，内心戏极多。
*   **名言**: “咋地？血条没空你还能给我送走啊？” / “这修仙界也太埋汰了，全是坑。”

### 苏灵韵 (Su Lingyun)
*   **原名**: 望舒
*   **身份**: 墨山道六师姐 / 掌门亲传
*   **核心设定**: “病娇奶妈”。
*   **性格**: 对陈道有着扭曲的占有欲和保护欲。喜欢看到陈道“残缺”或“濒死”的状态，认为那是最美的。擅长“痛苦治愈”（物理缝合、毒药回血）。
*   **互动**: 陈道负责抗伤，她负责（痛苦地）把陈道奶回来。

### 青禾 (Qing He)
*   **身份**: 苏灵韵的贴身伴读（实为姐姐） / 没落世家孤女
*   **背景**: 本是凡俗世家的大小姐，家族遭难后被张守愚救下。因其母与张守愚的亡妻是表亲，故被带回墨山道。虽然名义上是侍女，但实则是被寄养在青鸾峰避祸的。
*   **性格**: 知心大姐姐，温婉大气，处变不惊。她不惧怕苏灵韵的病娇（因为从小看着苏长大），反而像姐姐一样照顾着苏和陈道。
*   **互动**: 经常给陈道开小灶，甚至会温柔地化解苏灵韵过激的行为。陈道在她面前是个乖巧的弟弟，苏灵韵在她面前是个任性的妹妹。

### 张守愚 (Zhang Shouyu)
*   **原名**: 张九皋 / 张老鬼
*   **道号**: 玄微真人
*   **身份**: 墨山道传功长老（表面）/ 复仇者（暗线）
*   **外号**: “老鹤”、“愚道人”
*   **形象**: 邋遢的老道士，看似愚钝守拙，实则心机深沉（大智若愚）。
*   **故事**: 背负血海深仇（道侣被杀）。利用《无相经》（外挂）将诸多弟子培养成“死士”，最终以侄子的命换取复仇的机会。
*   **结局**: 因“开挂”破坏游戏平衡，被全服通缉（叛逃）。

### 墨家巨子 (The Juzi)
*   **原名**: 沈炼 (Shen Lian)
*   **道号**:  巨子
*   **身份**: 墨山道现任掌门 / 大能（机关学 + 物理格斗，能开24重）
*   **核心设定**: **“穿正装的悍匪”**。
*   **形象**: 穿着一丝不苟的黑色法袍，梳得整整齐齐，腰间佩戴一把漆黑的**横刀**（唐刀）。看着像个讲理的官方人员（锦衣卫/教父），实则骨子里透着“管杀不管埋”的狠劲。
*   **性格**: 表面讲规矩、讲礼貌，但这种“文明”反而更让人害怕。一旦动手，绝对残暴。
*   **名言**: “本座沈炼。以前杀人，现在讲理。你最好听我讲理，不然我还是得杀人。”

### 王道元 (Wang Daoyuan)
*   **原名**: 姚玄洲 / 姚真人 / 王富贵
*   **道号**: 多宝真人
*   **身份**: 算是墨山道内门长老，但主管外门一切事务，算是外门一把手（大管家）。
*   **形象**: 总是笑眯眯的胖子，穿着金钱纹锦袍，背着一把并不显眼的黑鞘长剑（墨山剑）。看着像和气生财的掌柜，实则是深藏不露的剑修。
*   **实力**: 真正的GM级人物。出手即秒杀。代表宗门（官方）维护服务器秩序。
*   **名言**: “和气生财，和气生财。买命钱付一下？”/ “别总惦记死人的东西，晦气。这是里子该收拾的。”


### 吴铁生 (Wu Tiesheng)
*   **曾用名**: 吴劲秋 (Wu Jinqiu)
*   **身份**: 墨山道戒律长老 / 刑堂堂主
*   **外号**: “老疯子”、“吴铁面”
*   **形象**: 像个务农的老汉，皮肤黝黑，满手老茧。腰间挂着一串充满煞气的“打神鞭”。
*   **性格**: 刚正不阿，嫉恶如仇。极度痛恨权贵和官僚作风。
*   **核心背景**: **“痴儿不算人”**。
    *   六岁时因追纸鸢惊扰秦国贵人马车，导致全族七十三口被满门抄斩。
    *   他因吓傻了被监斩官当做“痴儿”放过。
    *   他的命是全家人的头颅换来的，所以活得极其沉重，发誓要维护宗门风骨，不愿做朝廷走狗。
    *   曾改名“吴劲秋”，寓意“疾风知劲草”。

## 反派与配角 (Villains & NPCs)

### 琅琊·南宫绝 (Nangong Jue - Langya Clan)
*   **原名**: 南宫无尘
*   **身份**: 琅琊仙族世子 / 氪金玩家
*   **设定**: 兵解转世的“复活币战士”。拥有顶级装备（皮肤、坐骑、光效）。
*   **性格**: 傲慢，视陈道等人为“穷逼/NPC”。
*   **结局**: 被张守愚用“外挂”强杀。

### 张小宝 (Zhang Xiaobao)
*   **原名**: 张翯 / 张七
*   **身份**: 张守愚的侄子 / 萌新玩家
*   **设定**: 呆萌，崇拜陈道和叔叔。
*   **真相**: 从小被种下《无相不动经》替身咒，是张守愚复仇计划中的“消耗品道具”。
*   **结局**: 在不知情的情况下，替叔叔承担了致命伤害暴毙。

### 赵景行 (Zhao Jingxing)
*   **原名**: 赵天霸
*   **身份**: 外门恶霸 / 炼气六层 / 赵家庶子
*   **设定**: 改掉了土气的名字，但改不掉嚣张的本质。为了在家族争宠，急需在试炼中表现。
*   **结局**: 在狩猎试炼中被陈道“以弱胜强”反杀。

### 李清河 (Li Qinghe)
*   **原名**: 李兴隆 / 赵四
*   **身份**: 墨山道外门执事 / 内廷（宦官）安插的暗子
*   **剧情**: 在“仙墓副本”中试图毁掉祥瑞并灭口陈道。被陈道利用机制反杀。尸体和遗物（包括罪证）被王道元回收。

### 慈恩大师 (Master Cien)
*   **原名**: 金虎 / 酒肉和尚
*   **身份**: 天台山魔修 / 金丹Boss
*   **剧情**: 在公会战中被陈道用床弩+毒药+控制技偷袭致死。名字叫“慈恩”，干的是“吃人”。

### 刘长青 (Cripple Liu)
*   **原名**: 刘拐子
*   **身份**: 墨山道外门执事
*   **性格**: 阴险小人，负责“新手村”引导。

### 玄天尊 (Xuan Tian Zun)
*   **原名**: 玄天宗（曾用名）
*   **身份**: 昆仑掌门 / 渡劫期大能
*   **形象**: 参考《蜀山传》郑伊健。白衣长发，面容沧桑沉稳，宗师气度。身后常伴有“日金轮”与“月金轮”两大法宝。
*   **性格**: 平和深邃，视万物如静水。
*   **名言**: “昆仑玄天尊，拜山。”
