# 《我把你当师姐，你却说师弟用药？》

**【类型】**：暗黑仙侠 / 游戏异界 / 凡人流 / 搞笑吐槽
**【标签】**：虽然是修仙但全是数据、病娇师姐、血条怪、老六主角

---

## 📖 作品简介

**“只要血条没空，神仙也杀不了我。”**

穿越到一个人吃人的暗黑修仙界，陈道发现这个世界对他来说，只是一个巨大的**“高难服”网游**。

别人修仙靠天赋、靠丹药、靠闭关。
陈道修仙靠**卡BUG**、**锁血条**、**以伤换伤**。

*   **【系统警告：你摄入了剧毒，HP -100/秒……】**
    *   陈道：没事，吃口红姜压压惊，只要回血速度比掉血快，这就叫“双倍修炼挂”。
*   **【敌人嘲讽：我这一剑下去，你必死无疑！】**
    *   陈道：经过计算，这一剑避开心脏3毫米，只会造成95%的重伤。虽然我会很疼，但作为一个刺客，你没了防备，就是具尸体。
*   **【宗门大比：所有人都以为那个浑身是血的杂役弟子死定了。】**
    *   陈道：不好意思，我才刚热身。

一把名为**“过河卒”**的黑剑，一个**“有进无退”**的狠人。
在这个满天神佛都想吃人的世界里，陈道硬是用一副**数据化的身体**，杀出了一条通天大道。

---

## 👥 主要人物

*   **陈道（主角）**：
    *   **设定**：“东北血牛刺客”。满嘴大碴子味的吐槽役，看着像个混不吝的该溜子，实则是为了生存不择手段的数据流高玩。
    *   **名言**：“咋地？血条没空你还能给我送走啊？”

*   **苏灵韵（六师姐）**：
    *   **设定**：“病娇奶妈”。墨山道其实也是个疯人院，而她是最大的那个疯子。
    *   **互动**：对陈道有着扭曲的保护欲。喜欢看陈道把血条打空，然后她负责（痛苦地）把他奶回来。

*   **青禾（贴身侍女/姐姐）**：
    *   **设定**：没落世家的大小姐，被寄养在青鸾峰的“隐形大佬”。
    *   **互动**：这冷酷仙门中唯一的温柔乡。苏灵韵唯一忌惮（或者说听话）的人。陈道背后的温暖港湾。

---

## 🔥 核心看点

1.  **【极致的数据修仙】**：不是无脑的系统流，而是利用游戏机制（伤害判定、状态刷新、卡位置）来破解修仙界的死局。
2.  **【不仅修仙，更修脑子】**：主角虽然有挂，但更多时候靠的是“老六”的思维和对人性的算计。
3.  **【又爽又惊悚】**：前一秒还在和师姐温馨互动（被威胁做成标本），后一秒就在乱葬岗和老鬼谈笑风生（物理超度）。
4.  **【全员恶人，也全员有情】**：在这个黑暗的世界里，每个人都有自己的生存法则。没有绝对的正义，只有活下去的执念。
