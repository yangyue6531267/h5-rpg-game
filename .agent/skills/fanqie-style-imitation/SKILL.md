# 番茄小说风格分析与仿写助手

## 1. 核心功能

本 Skill 用于：
1. **风格提取**：分析目标小说的语言风格、叙事节奏、爽点密度
2. **模式识别**：识别出作者的套路（如反转节奏、打脸频率、升级曲线）
3. **仿写指南**：生成可复用的写作规范，用于后续创作

---

## 2. 风格分析模板

当用户提供目标小说文本后，按以下维度分析：

### 2.1 语言风格 (Language Style)
```
【词汇层次】：□ 网文大白话 / □ 略有文采 / □ 古风典雅 / □ 现代都市
【对话特色】：（如：喜欢用省略号、爱用反问句、角色口癖等）
【叙述视角】：□ 第一人称 / □ 第三人称限知 / □ 全知视角
【禁忌词汇】：（作者明显回避的词，如不用"顿时"改用"登时"）
【高频词汇】：（作者爱用的词，如"瞬间"、"竟然"、"居然"）
【句式节奏】：□ 短句为主 / □ 长短交错 / □ 长句铺陈
```

### 2.2 叙事节奏 (Narrative Rhythm)
```
【章均字数】：约____字
【爽点密度】：每____字一个小爽点，每____章一个大高潮
【反转频率】：平均每章____次反转
【升级曲线】：□ 稳步提升 / □ 厚积薄发 / □ 跳跃式突破
【钩子设计】：（章末如何吊人胃口，如：神秘人出现、宝物即将到手）
```

### 2.3 人物塑造 (Character Design)
```
【主角人设】：（如：扮猪吃虎型、闷声发大财型、装逼打脸型）
【主角口头禅】：
【配角功能】：（如：舔狗、踏脚石、送资源、暖床）
【反派智商】：□ 送人头型 / □ 正常对手 / □ 高智商博弈
【女主类型】：（如：青梅竹马、高冷女神、妩媚狐狸精）
```

### 2.4 爽点套路 (Power Fantasy Patterns)
```
【打脸模式】：
  - 频率：每____章一次
  - 套路：（如：先被嘲讽→亮底牌→打脸→围观群众震惊）

【装逼模式】：
  - 触发条件：（如：被人看不起时）
  - 经典台词：

【升级模式】：
  - 资源来源：（如：杀人夺宝、奇遇、老爷爷送）
  - 突破仪式：（如：雷劫、闭关、顿悟）

【收小弟模式】：
  - 收服方式：（如：打服、救命之恩、利益交换）
```

## 4. 使用工作流

### Step 1: 导入目标文本
```
用户指令："分析这段文本的风格"
→ 粘贴目标小说的3-5章内容（约1-2万字最佳）
```

### Step 2: 执行分析
```
AI 输出：
1. 完整的风格分析报告（按2.1-2.4模板）
2. 生成仿写规范文档
```

### Step 3: 仿写创作
```
用户指令："按照刚才的风格，写一章XXXX剧情"
→ AI 根据规范文档 + 用户大纲进行仿写
→ 用户修改反馈 → 持续迭代
```

## 5. 番茄小说通用特征

以下是番茄平台头部作品的共性特征，可作为基础参考：

### 5.1 节奏特征
- **短章高频**：章均1500-2500字，适合碎片化阅读
- **钩子密集**：每章结尾必有悬念
- **快速入戏**：第一章30%内必须出现核心冲突

### 5.2 语言特征
- **口语化**：怎么说话怎么写，不装文艺
- **网络梗**：适当使用热梗，增加代入感
- **短句爆发**：高潮时用短句叠加，制造冲击感

### 5.3 爽点特征
- **降智打脸**：反派智商在线时间不超过3章
- **数据可视**：战力、等级、金钱最好有具体数字
- **碾压快感**：以弱胜强只是过程，碾压虐菜才是归宿

### 5.4 禁忌特征
- **禁止拖沓**：不要大段心理描写、不要长篇景物描写
- **禁止圣母**：主角不能圣母婊，对敌人必须狠
- **禁止虐主**：虐主时间不能超过2章，必须马上反杀
