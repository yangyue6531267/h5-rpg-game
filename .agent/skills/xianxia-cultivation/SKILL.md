# 修仙/仙侠创作助手

## 核心功能

本 Skill 专注于提供**深度**的修仙元素设计和写作指导，填补 `setting-detector` 仅提供知识库的空白。

## 写作禁忌 (Taboos)
- **拒绝凡俗化**：高阶修士（金丹及以上）禁止出现“把玩”物品（如铁胆、核桃、珠子）的动作描写，这会降低人物逼格。
- **仙家气象**：大修应重“意”不重“形”，举手投足间引动天地灵气，而非依赖手中玩物。

## 常用指令

### 1. 世界观/设定生成
- **宗门设计**：生成的宗门包含名称、位置（灵脉）、特色功法、主要人物（掌门/老祖）、镇派之宝。
- **修炼体系**：除了传统的炼气筑基，设计独特的升级体系（如以蛊修仙、以画入道）。
- **地图生成**：设计包含禁地、各方势力分布的大地图概念。

### 2. 物品/功法生成
- **功法/神通**：名称、品阶、修炼条件、威力描述、副作用。
- **神兵/法宝**：名称、外形、材质、器灵设定、特殊效果。
- **丹药/灵草**：名称、药效、生长环境、炼制难度。

### 3. 情节辅助
- **秘境探险**：设计秘境机制、关卡挑战、最终奖励、竞争对手。
- **宗门大比**：设计赛制、主角的晋级路线、对手的招式。
- **拍卖会**：设计压轴拍品、竞价冲突、杀人夺宝的伏笔。
- **渡劫场景**：设计雷劫重数、心魔劫内容、护道危机。

## 提示词模板 (Prompts)

### 设定生成：宗门
```markdown
请设计一个[正道/魔道/中立]宗门。
- 名称风格：[飘逸/霸气/诡异]
- 核心道法：[剑道/丹道/阵法/合欢/炼体]
- 当前处境：[鼎盛/衰落/内斗]

输出要求：
1. 宗门名称与诗号
2. 宗门等级（一品至九品）
3. 镇派功法与绝学（3个）
4. 标志性建筑/地理环境
5. 3个关键NPC（名字+简短性格+修为）
```

### 设定生成：功法
```markdown
请为主角设计一本[品阶]核心功法。
- 属性：[火/雷/空间/吞噬]
- 特点：[修炼极快但有隐患/威力巨大但消耗大/注重防御]

输出要求：
1. 功法名称（要有逼格）
2. 核心口诀（2句古风诗词）
3. 修炼出的特殊灵力/异象描述
4. 配套的3个神通（低级、中级、终极大招）
```

### 剧情生成：秘境
```markdown
请设计一个适合[主角当前境界]探索的秘境。
- 类型：[上古战场/大能洞府/妖兽巢穴]
- 开启方式：[定期开启/信物开启/意外崩塌]

输出要求：
1. 秘境环境特色与环境危机（毒雾、重力等）
2. 3个关键探索节点/关卡
3. 最终机缘/宝物
4. 潜在的竞争者或阴谋
```

## 独特的修仙元素表 (Flavor Text)

当用户需要润色描写时，参考以下词汇：

**灵力描写**：
- 氤氲、澎湃、凝练、粘稠如水、狂暴、枯竭、生生不息
- 灵气化形、罡风凛冽、紫气东来

**战斗描写**：
- 掐诀、祭出、迎风便涨、灵压、护体灵光、神识锁定
- 摧枯拉朽、撼动天地、空间撕裂、法相天地

**突破描写**：
- 瓶颈松动、如隔膜破碎、洗筋伐髓、脱胎换骨
- 天地异象、雷云凝聚、心魔滋生、道心通明
