# 使用示例

## 示例1：单一类型检测

### 用户输入
```
我想写一部悬疑小说
```

### 系统响应
```
📚 检测到类型关键词

已激活知识库：
✓ mystery.md（悬疑推理创作惯例）

悬疑小说的核心要素：
1. 谜团设计 - 需要一个引人入胜的核心谜团
2. 线索布局 - 公平展示线索，允许读者推理
3. 反转与揭秘 - 合理的真相揭示

需要我帮你规划故事结构吗？
```

## 示例2：多类型融合

### 用户输入
```
我要写一个民国时期的言情复仇故事
```

### 系统响应
```
📚 检测到多个类型关键词

已激活知识库：
✓ romance.md（言情创作惯例）
✓ revenge.md（复仇爽文技巧）
✓ china-1920s/（1920年代历史参考）

这是一个【民国言情+复仇】的组合类型！

融合建议：
- 感情线是主情节（言情核心）
- 复仇作为推动剧情的动力
- 民国背景提供时代氛围

建议Token分配：
~520 tokens（言情） + ~480 tokens（复仇） + ~650 tokens（民国）
```

## 示例3：创作过程中持续应用

### 第一轮
```
用户：我要写小说
AI：好的！请告诉我更多信息，比如类型、背景等？
（未激活任何知识库）
```

### 第二轮
```
用户：主角是个侦探
AI：✓ 已激活 mystery.md
    侦探类型小说需要注意...
```

### 第三轮
```
用户：还有感情线
AI：✓ 额外激活 romance.md
    浪漫悬疑的融合要点...
    
    当前激活：mystery + romance
```

## 示例4：手动控制

### 查看状态
```
用户：当前激活了哪些知识库？

AI：📚 当前激活的知识库：
    ✓ genres/romance.md - 言情小说创作惯例
    ✓ genres/revenge.md - 复仇爽文技巧
    ✓ references/china-1920s/ - 1920年代中国参考
    
    Token消耗：约1650 tokens
```

### 手动激活
```
用户：请加载武侠知识库

AI：✓ 已激活 wuxia.md
    武侠元素已添加到当前知识库
```

### 停用知识库
```
用户：停用revenge知识库，不需要复仇元素

AI：✓ 已停用 revenge.md
    当前激活：romance + china-1920s
```

## 示例5：与requirement-detector协同

### 用户输入
```

```

### 系统响应
```
📚 setting-detector 激活：
✓ romance.md（言情）
✓ china-1920s/（民国背景）

📋 requirement-detector 激活：
✓ fast-paced（爽文节奏）

最终效果：
- 民国言情类型知识指导
- 快节奏爽文结构
- 极致口语化表达
```
