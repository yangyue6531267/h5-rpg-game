# 修仙/仙侠小说创作知识库

## 核心定义 (Core Definition)
**类型特点**：以“提升境界、追求长生”为核心驱动力，构建宏大的力量升级体系。
**核心爽点**：突破境界、扮猪吃虎、越阶挑战、捡漏夺宝、人前显圣。

---

## 境界体系 (Cultivation Realms)
> 这是一个经典且通用的境界体系，可根据设定微调。

1.  **炼气期 (Qi Condensation)**
    *   **特征**：引气入体，踏入仙途，可以使用低级法术。
    *   **寿元**：100-150岁。
    *   **关卡**：炼气一层至九层（或十层圆满）。

2.  **筑基期 (Foundation Establishment)**
    *   **特征**：铸造道基，法力液化，可御剑飞行，被称为“陆地神仙”。
    *   **寿元**：200-300岁。
    *   **突破**：需[筑基丹]辅助，失败率高。

3.  **金丹期 (Golden Core)**
    *   **特征**：体内结丹，法力固化，神通大增，是一方高手的标志。
    *   **寿元**：500-800岁。
    *   **分类**：丹成九品（一品金丹最强）。

4.  **元婴期 (Nascent Soul)**
    *   **特征**：碎丹成婴，肉身毁坏元婴可夺舍重生，拥有第二条命。
    *   **寿元**：1000-2000岁。
    *   **地位**：老祖级别，通常是宗门的最高战力。

5.  **化神期 (Spirit Severing / Soul Transformation)**
    *   **特征**：感悟天地法则，神识化千，不再拘泥于形体。
    *   **寿元**：3000-5000岁。

6.  **后续境界**：
    *   炼虚 (Void Refinement)
    *   合体 (Body Integration)
    *   大乘 (Mahayana / Great Vehicle)
    *   渡劫 (Tribulation Transcendence) → 飞升仙界

## 常见世界观元素 (World Building)

### 势力架构
*   **宗门 (Sects)**：由于修炼资源垄断而形成的组织，分外门、内门、真传、执事、长老、掌门、太上长老。
*   **家族 (Clans)**：以血缘为纽带的势力，通常依附于大宗门或掌控世俗界。
*   **散修 (Rogue Cultivators)**：无门无派，资源匮乏，行事通常更加狠辣小心。

### 资源体系 (财侣法地)
*   **财 (Wealth)**：灵石（下品、中品、上品、极品）、丹药、法宝。
*   **侣 (Companions)**：道侣、同门、护道者、灵兽。
*   **法 (Techniques)**：功法（练气根本）、神通（法术技能）、秘术（爆发/逃生）。
*   **地 (Land)**：洞天福地、灵脉等级决定修炼速度。

## 经典套路与节奏 (Tropes & Beats)

### 开局流派
1.  **废柴退婚流**：天赋低微被羞辱 → 获得金手指 → 打脸翻身。
2.  **天才陨落流**：昔日天才一朝沦为废人 → 查明真相重回巅峰。
3.  **凡人修仙流**：资质平平，靠心智、算计和坚韧不拔一步步爬升。
4.  **重生/穿越流**：带着前世记忆/系统/现代知识降维打击。

### 常用爽点模式
1.  **拍卖会捡漏**：主角看出别人不识货的宝物。
2.  **秘境试炼**：宗门大比或古迹探险，获得传承，杀人夺宝。
3.  **越阶挑战**：仗着功法/法宝强大，炼气期斩杀筑基期。
4.  **扮猪吃虎**：隐藏修为，让反派轻敌，最后雷霆一击。

### 冲突来源
*   **杀人夺宝**：修仙界残酷，怀璧其罪。
*   **道统之争**：正魔对立，不同宗门理念冲突。
*   **资源争夺**：灵石矿脉、遗迹归属。
*   **因果复仇**：打了小的来老的。

## 写作建议 (Tips from Dataset)
1.  **战力崩坏控制**：前期不要把数值写得太大，给换地图留空间。
2.  **金手指限制**：金手指不能万能，要有代价或限制，否则剧情无张力。
3.  **反派智商**：反派不应只是无脑嘲讽，要是为了利益驱动的理性行动者。
4.  **所谓"道"**：后期需要阐述主角的"道心"（为何修仙），升华主题。
